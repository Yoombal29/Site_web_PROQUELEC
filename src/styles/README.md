# PROQUELEC CSS Design System

Les classes `pq-*` forment la bibliotheque visuelle officielle du site public et des modeles Builder.

Organisation :

- `design-tokens.css` : variables, theme clair/sombre et base Tailwind.
- `pq-layout.css` : conteneurs et structure globale.
- `pq-section.css` : sections, hero et variantes premium.
- `pq-grid.css` : grilles reutilisables.
- `pq-button.css` : boutons et variantes.
- `pq-stat.css` : indicateurs et chiffres cles.
- `pq-card.css` : cartes, services, highlights et variantes premium.
- `pq-alert.css` : messages d'information, succes, alerte et danger.
- `pq-workflow.css` : etapes, checklists, resultats.
- `pq-form.css` : champs de formulaire.
- `pq-table.css` : tableaux.
- `pq-builder.css` : moteur responsive du Builder et namespace `pb-*`.
- `animations.css` : animations et utilitaires globaux.

Regle d'architecture : les modeles officiels doivent utiliser ces classes stables plutot que des classes Tailwind arbitraires.
